# CienMath V13.8.21 · Bachillerato (Demo)

- Interruptor **Bachillerato** en Crear clases y en el editor de una clase existente.
- El atributo se conserva al crear, repetir, duplicar, resolver coincidencias, publicar y guardar por profesor.
- Las clases de Bachillerato aparecen con color naranja en la vista de estudiantes; una vez agotados los cupos se muestran como reservadas en violeta.
- La reserva DEMO conserva la etiqueta Bachillerato y el panel del administrador la muestra junto a la materia.
- El selector de nivel del estudiante permanece independiente: indica el nivel del alumno, no altera la categoría de la clase.
- **Sin cambios** en autenticación, lógica de cupos, mensajes, envíos ni estilos del lobby. Datos solo locales.

## Prueba rápida
1. Ingresar como profesor y crear una clase futura marcando **Bachillerato**. Elegir materia, modalidad y cupo, luego publicar.
2. Abrir Estudiantes y seleccionar el profesor. La clase debe verse naranja y decir **Bachillerato**.
3. Reservar la clase como estudiante. Confirmar que aparece el comprobante y disminuye el cupo.
4. Entrar como administrador y comprobar la reserva en **Reservaciones recibidas**.
5. Opcional: editar una clase sin reservas, activar/desactivar Bachillerato, y probar repetir/duplicar.

**Importante:** sigue siendo un prototipo local, sin pagos ni correos/SMS reales.
