# CienMath V13.8.18 · Lobby institucional de demostración

## Navegación
- `index.html`: lobby institucional (nuevo inicio).
- `estudiantes.html`: consulta de horarios, reservas aún simuladas.
- `profesores.html`: gestión de profesores en almacenamiento local, sin seguridad.
- `horarios.html`: constructor de horarios original (antes `index.html`).
- El botón **Acceso · Demo** abre accesos a las herramientas, sin pedir credenciales.

## Alcance
- Portada y secciones institucionales, navegación, tema claro/oscuro, menú móvil, diálogos informativos.
- Se conserva la lógica de las herramientas; solo se ajusta la ruta del calendario de profesores.
- Arte de portada derivado del concepto visual de CienMath aprobado durante el diseño.
- Fechas sin año, precios y reglamentos pendientes de aprobación del cliente.
- No existe autenticación real, base de datos compartida, reservas transaccionales ni cobros.
- Para la demo no se deben ingresar datos reales de estudiantes o profesores.

## Publicación
Puede mostrarse como demo estática en GitHub Pages. No debe anunciarse como plataforma operativa de reservas.

## Revisión pendiente
El cliente debe validar contenidos, precios, ciclo lectivo, logo final y alcance antes de producción.
